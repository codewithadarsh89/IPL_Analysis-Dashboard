# IPL_Analysis-Dashboard
MS Excel Dashboard on IPL dataset from 2008 to 2018
# Project Overview
This project focuses on analyzing Indian Premier League (IPL) data from 2008 to 2018 to extract meaningful insights about player performance, match outcomes, and winning patterns.
The analysis is performed using Microsoft Excel, leveraging advanced features like Pivot Tables, Power Query, and data cleaning techniques to transform raw data into actionable insights.

# 🎯 Objectives
Analyze player performance across seasons
Identify winning patterns and trends
Determine best batsmen and bowlers
Understand toss impact on match results
Explore venue-based match outcomes

# 🛠️ Tools & Technologies

Pivot Tables

Data Cleaning Techniques
